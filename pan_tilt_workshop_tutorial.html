Build a phone-controlled pan-tilt platform in 2 hours

Not yet tested on hardware. Both sketches pass a syntax check against stub headers only. Build and test one complete kit of each board type you plan to use, with the exact parts you will hand out. Why two power supplies? The board gets its power from your laptop’s USB cable (or later a second bank or charger). The servos get theirs from the power bank. The grounds are joined, nothing else is. This is the habit you want for anything with motors. Don’t use four fresh alkaline AA cells for servos rated 6 V: they start near 6.4 V.
Safety in five lines
  • Nothing moves until you pass the gates. Fit the servo horns only after the servos are centred.
  • The board is a 3.3 V device. Never feed the 5 V servo rail into a pin.
  • The capacitor has a long leg (+) and a stripe (−). Reverse it and it can fail loudly.
  • Don’t force a powered servo by hand, and don’t drive it into a stop. That strips gears and heats the servo.
  • Unplug the power bank whenever you change wiring. Servos jump to the centre at the first power-up, so keep fingers clear.
The 5 V source: USB-C power bank and breakout board

A USB-C power bank stays off until it sees a 5.1 kΩ resistor from each CC pin to ground. A bare cut cable has none, so it usually gives 0 V. A breakout board with those resistors fixes that. Instructors prepare this ahead of the workshop, and attendees only measure it.

Saved separately as usbc_breakout_wiring.png.

Prepare the breakout (instructor, before the workshop)

  1. With the bank unplugged, measure CC1 to GND and CC2 to GND. About 5.1 kΩ on both means the resistors are fitted. An open circuit means you add them.
  2. If needed, fit one 5.1 kΩ resistor from CC1 to GND and another from CC2 to GND. Keep them separate. Never join CC1 and CC2.
  3. Find VBUS and GND. Some boards label VBUS as VCC, V+, or 5V. Plug in the bank and measure: with black on GND, the pad that reads about 5 V is VBUS.
  4. Attach a red lead to VBUS and a black lead to GND. Leave D+, D−, SBU1, and SBU2 empty.
  5. Confirm about 5 V with the red lead positive, and leave it on for a minute to check that the bank doesn’t switch itself off.
  6. Repeat with every power-bank model you will hand out.

Prompt for the ESP32 (main choice) 
I'm building a pan-tilt platform. Write an Arduino sketch for an ESP32 DevKit (Arduino-ESP32 core 3.x) that moves two hobby servos from a web page on my phone.

Hardware facts:
- Pan servo signal = GPIO18. Tilt servo signal = GPIO19.
- The servos are powered from a separate 5 V supply (USB power bank). Grounds are common. ESP32 logic is 3.3 V.
- Micro servos (SG90 type), 50 Hz PWM. The exact pulse range is uncertain, so make it a named constant (start with 500 to 2400 microseconds).
- Mechanical limits: pan 30 to 150 degrees, tilt 50 to 130 degrees. Never command outside them.

Requirements:
- The ESP32 creates its own Wi-Fi access point (SSID PT-xx, WPA2 password, channel 1).
- The web page is served from the ESP32 itself and has a pan slider, a tilt slider and a centre button.
- The page sends the target angles every 200 ms. If no command arrives for 1.2 s, the platform moves back to the centre.
- Movement is slew-limited to 90 degrees per second. No instant jumps.
- Both servos go to the centre (90 degrees) at boot.
- Limits are enforced in firmware, not only in the page.
- No delay() calls in the main loop.

Read the assumptions list before you read the code. Every assumption is a hypothesis to check.

Expect at least one surprise. Many AI answers use the older ESP32 PWM functions (ledcSetup, ledcAttachPin) or a servo library you haven’t installed. On core 3.x the old functions don’t exist, and you get a compile error. For the ESP8266, a classic crash comes from sending a page stored in flash with the wrong function. Servos also differ in pulse range: a value that is right for one servo can strain another.

Step 6: Centre, fit, calibrate (20 min)
  1. Unplug the board’s USB cable and the power bank. Plug the servos into the header strips (check the orientation: GND, 5 V, signal).
  2. Plug in the power bank, then the USB cable. Both servos move to the centre. Keep fingers clear.
  3. With the power still on, fit the servo horns and the bracket so the platform faces straight ahead and level.
  4. Move the sliders slowly towards each end. Listen. A servo that buzzes or strains is pushing against a stop.
  5. Note the angles where the bracket first touches. Set PAN_MIN, PAN_MAX, TILT_MIN, and TILT_MAX at least 10° inside those stops. Re-flash.
  6. If a servo moves the wrong way, flip PAN_INVERT or TILT_INVERT. Don’t swap wires.

Running without the laptop

Once the sketch is uploaded it lives in the board’s flash memory and starts by itself whenever the board gets power. The laptop is only needed to upload code and to read the Serial Monitor. Your phone does the controlling over the board’s own Wi-Fi network.

  • Power the board from a second USB power bank, a bank with two ports, or a USB charger, through its USB port.
  • The servo rail stays as it is. Keep the board’s GND wire to the − rail, because both supplies need a common ground.
  • Switch on the servo power first, then the board’s supply.
  • Some power banks switch off when the draw is very low, and a plain ESP32 or ESP8266 draws little. Leave it running for several minutes to check, or use a wall charger.
  • You lose the Serial Monitor, so test everything with the laptop first. The address is still 192.168.4.1.
  • Repeat the failsafe test from step 7 on the standalone supply.

Avoid powering the board from the servo rail. Servo spikes can make it reset, and the two supplies are the point of the exercise.

Print notes for the bracket
  • Several free pan-tilt brackets for SG90 and MG90S servos exist on Thingiverse, Printables, Cults3D, MakerWorld, and CGTrader. Search for “pan tilt SG90” or “pan tilt MG90S”, download from the original site, and check each model’s license before printing a batch.
  • Measure your servos before printing, and print one fit-test copy first. Thin screw holes on some designs crack.
  • Make the bracket’s hard stops sit a little beyond the firmware limits (the tutorial assumes about pan 30 to 150 and tilt 50 to 130). Firmware stops first, plastic second. Some designs tilt more downward than upward, so adjust the tilt limits to match.
  • Leave a cable channel and a screw-down plate for the breadboard and board on the base.
  • Add a mounting plate on the tilt arm for a small camera if you plan the add-on.
  • Print one or two spares, and time one print before you multiply by the number of kits.

// Pan-tilt workshop sketch: ESP32 + 2 hobby servos, aimed from a phone browser.
// Needs: Arduino-ESP32 core 3.x (ledcAttach / ledcWrite take a pin number).
//
// Safety design:
//  - Angle limits are enforced here in firmware, not only in the web page.
//  - Movement is slew-limited, so the servos never jump to a new angle.
//  - The phone sends the target every 200 ms. If commands stop for FAILSAFE_MS,
//    the platform moves back to the centre by itself.
//  - Both servos go to the centre at boot.

#include <WiFi.h>
#include <WebServer.h>

// ---------- Wiring (keep in sync with the pin table) ----------
const int PAN_PIN  = 18;
const int TILT_PIN = 19;

// ---------- Settings ----------
const char*   AP_SSID    = "PT-01";           // unique per unit
const char*   AP_PASS    = "change-me-1234";  // change this (8+ characters)
const uint8_t AP_CHANNEL = 1;                 // use 1, 6 or 11

// Angle limits in degrees. Calibrate on your bracket, then stay inside the hard stops.
const float PAN_MIN  = 30, PAN_MAX  = 150, PAN_CENTER  = 90;
const float TILT_MIN = 50, TILT_MAX = 130, TILT_CENTER = 90;

// If a servo moves the wrong way, flip it here instead of rewiring.
const bool PAN_INVERT  = false;
const bool TILT_INVERT = false;

// Pulse width (microseconds) that maps to 0 and 180 degrees. Servos differ: calibrate.
const int PULSE_MIN_US = 500;
const int PULSE_MAX_US = 2400;

const float         SLEW_DEG_PER_S = 90.0;  // maximum speed
const unsigned long FAILSAFE_MS    = 1200;  // no command for this long: go to centre
const unsigned long STEP_MS        = 20;    // control step

const int PWM_FREQ = 50;  // servo frame rate in Hz
const int PWM_BITS = 14;  // duty resolution

WebServer server(80);
float curPan = PAN_CENTER, curTilt = TILT_CENTER;
float tgtPan = PAN_CENTER, tgtTilt = TILT_CENTER;
unsigned long lastCmd = 0;
unsigned long lastStep = 0;

// Write one servo. deg is 0..180 before inversion.
void writeServo(int pin, float deg, bool invert) {
  if (invert) deg = 180.0 - deg;
  deg = constrain(deg, 0.0, 180.0);
  float us = PULSE_MIN_US + (PULSE_MAX_US - PULSE_MIN_US) * deg / 180.0;
  uint32_t duty = (uint32_t)(us * ((1 << PWM_BITS) - 1) / 20000.0);  // 20 ms frame
  ledcWrite(pin, duty);
}

float stepToward(float cur, float tgt, float maxStep) {
  if (tgt > cur) return min(cur + maxStep, tgt);
  return max(cur - maxStep, tgt);
}

void handleRoot() {
  server.send(200, "text/html", INDEX_HTML);
}

void handleInfo() {
  char buf[112];
  snprintf(buf, sizeof(buf),
           "{\"pmin\":%d,\"pmax\":%d,\"tmin\":%d,\"tmax\":%d,\"pc\":%d,\"tc\":%d}",
           (int)PAN_MIN, (int)PAN_MAX, (int)TILT_MIN, (int)TILT_MAX,
           (int)PAN_CENTER, (int)TILT_CENTER);
  server.send(200, "application/json", buf);
}

void handleAim() {
  if (!server.hasArg("p") || !server.hasArg("t")) {
    server.send(400, "text/plain", "need p and t");
    return;
  }
  tgtPan  = constrain((float)server.arg("p").toInt(), PAN_MIN, PAN_MAX);
  tgtTilt = constrain((float)server.arg("t").toInt(), TILT_MIN, TILT_MAX);
  lastCmd = millis();
  server.send(200, "text/plain", "OK");
}

void setup() {
  Serial.begin(115200);

  bool ok1 = ledcAttach(PAN_PIN, PWM_FREQ, PWM_BITS);
  bool ok2 = ledcAttach(TILT_PIN, PWM_FREQ, PWM_BITS);
  if (!ok1 || !ok2) Serial.println("PWM setup failed: check pins and core version");
  writeServo(PAN_PIN, curPan, PAN_INVERT);     // centre at boot
  writeServo(TILT_PIN, curTilt, TILT_INVERT);

  WiFi.mode(WIFI_AP);
  WiFi.softAP(AP_SSID, AP_PASS, AP_CHANNEL);
  Serial.print("Wi-Fi: ");
  Serial.print(AP_SSID);
  Serial.print("  open http://");
  Serial.println(WiFi.softAPIP());

  server.on("/", handleRoot);
  server.on("/info", handleInfo);
  server.on("/aim", handleAim);
  server.begin();
}

void loop() {
  server.handleClient();

  unsigned long now = millis();
  if (now - lastStep >= STEP_MS) {
    float dt = (now - lastStep) / 1000.0;
    lastStep = now;

    if (now - lastCmd > FAILSAFE_MS) {  // commands stopped: return to centre
      tgtPan = PAN_CENTER;
      tgtTilt = TILT_CENTER;
    }

    float maxStep = SLEW_DEG_PER_S * dt;
    curPan  = stepToward(curPan, tgtPan, maxStep);
    curTilt = stepToward(curTilt, tgtTilt, maxStep);
    writeServo(PAN_PIN, curPan, PAN_INVERT);
    writeServo(TILT_PIN, curTilt, TILT_INVERT);
  }
}

// Write one servo. deg is 0..180 before inversion.
void writeServo(Servo &servo, float deg, bool invert) {
  if (invert) deg = 180.0 - deg;
  deg = constrain(deg, 0.0, 180.0);
  int us = PULSE_MIN_US + (int)((PULSE_MAX_US - PULSE_MIN_US) * deg / 180.0);
  servo.writeMicroseconds(us);
}

float stepToward(float cur, float tgt, float maxStep) {
  if (tgt > cur) return min(cur + maxStep, tgt);
  return max(cur - maxStep, tgt);
}

void handleRoot() {
  server.send_P(200, "text/html", INDEX_HTML);  // page lives in flash, so use send_P
}

void handleInfo() {
  char buf[112];
  snprintf(buf, sizeof(buf),
           "{\"pmin\":%d,\"pmax\":%d,\"tmin\":%d,\"tmax\":%d,\"pc\":%d,\"tc\":%d}",
           (int)PAN_MIN, (int)PAN_MAX, (int)TILT_MIN, (int)TILT_MAX,
           (int)PAN_CENTER, (int)TILT_CENTER);
  server.send(200, "application/json", buf);
}

void handleAim() {
  if (!server.hasArg("p") || !server.hasArg("t")) {
    server.send(400, "text/plain", "need p and t");
    return;
  }
  tgtPan  = constrain((float)server.arg("p").toInt(), PAN_MIN, PAN_MAX);
  tgtTilt = constrain((float)server.arg("t").toInt(), TILT_MIN, TILT_MAX);
  lastCmd = millis();
  server.send(200, "text/plain", "OK");
}

void setup() {
  Serial.begin(115200);

  panServo.attach(PAN_PIN, PULSE_MIN_US, PULSE_MAX_US);
  tiltServo.attach(TILT_PIN, PULSE_MIN_US, PULSE_MAX_US);
  writeServo(panServo, curPan, PAN_INVERT);     // centre at boot
  writeServo(tiltServo, curTilt, TILT_INVERT);

  WiFi.mode(WIFI_AP);
  WiFi.softAP(AP_SSID, AP_PASS, AP_CHANNEL);
  Serial.println();
  Serial.print("Wi-Fi: ");
  Serial.print(AP_SSID);
  Serial.print("  open http://");
  Serial.println(WiFi.softAPIP());

  server.on("/", handleRoot);
  server.on("/info", handleInfo);
  server.on("/aim", handleAim);
  server.begin();
}

void loop() {
  server.handleClient();

  unsigned long now = millis();
  if (now - lastStep >= STEP_MS) {
    float dt = (now - lastStep) / 1000.0;
    lastStep = now;

    if (now - lastCmd > FAILSAFE_MS) {  // commands stopped: return to centre
      tgtPan = PAN_CENTER;
      tgtTilt = TILT_CENTER;
    }

    float maxStep = SLEW_DEG_PER_S * dt;
    curPan  = stepToward(curPan, tgtPan, maxStep);
    curTilt = stepToward(curTilt, tgtTilt, maxStep);
    writeServo(panServo, curPan, PAN_INVERT);
    writeServo(tiltServo, curTilt, TILT_INVERT);
  }
}
